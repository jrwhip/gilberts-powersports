# UTV / Side-by-Side Landing Pages — Complete Content

Kristi wants separate landing pages for each Segway UTV model line they sell. She created a detailed document with wireframes, pricing, and full spec comparison tables for each model.

Her instruction: "This set up on each landing site for the different Models. Then below this have the specs table of the model comparing the different features."

---

## Page Layout (Kristi's Wireframe — Applies to Every UTV Landing Page)

Kristi drew a wireframe that should be the template for each model's page:

**Header area:**
- Gilbert logo (top left)
- "other things we put up here & I forgot" (top right) — meaning standard nav items
- Contact Us link (top right)

**Hero section:**
- Video running behind, banner like the main page
- Large model name (e.g. "UT 6")
- "STARTING AT $[lowest price] MSRP*"
- Row of buttons that switch between model trims (e.g. "UT6P", "UT6M", "UT6") — buttons change the image to match the selected model

**Product display:**
- Side by side picture (left)
- Year, Model, Price* (right of image)
- Footnote: "* MSRP does not include freight, prep or dealer set up"

**Below the product display:**
- Full specs comparison table for that model line
